Files
  index.html   the whole website (one file: design, text, scripts)

HOST IT (free, 2 minutes) — any one option:

1) Netlify Drop (easiest)
   - Unzip this file.
   - Open https://app.netlify.com/drop
   - Drag the "ayush-tech-portfolio" folder onto the page. Done — you get a live link.
   - Sign in to keep it and rename the site (e.g. ayush-sharma.netlify.app).

2) Vercel
   - https://vercel.com/new -> deploy the "ayush-tech-portfolio" folder (no build settings needed).

3) Firebase (your old portfolio: ayush-sharma-portfolio.web.app)
   - Replace the files in your Firebase "public" folder with these, then run:  firebase deploy

4) GitHub Pages
   - New public repo -> Add file > Upload files -> upload index.html (at the repo root, not inside a folder)
   - Settings > Pages > Deploy from a branch > main / (root) > Save
   - Live in 1-2 min at https://<username>.github.io/<repo-name>/

Notes
  - Opening index.html by double-click also works for a quick local check.
